The assembly kernels this repository's Rust crate embeds via
`core::arch::global_asm!` (preprocessed by `build.rs` with zero C
compiler or third-party build dependencies). Every exported symbol is
`blake3_servil_*`, so a binary that links this crate and official BLAKE3
keeps each one's kernels apart.

- AArch64: the integer + NEON kernels (`blake3_neon_hybrid_aarch64.S`,
  generated by `tools/gen_neon_hybrid.py`), the SME2 kernels
  (`blake3_sme2_aarch64.S`; `blake3_sme2_hybrid_aarch64.S`, generated by
  `tools/gen_sme2_hybrid.py`), the independent-compression output kernels
  (`blake3_output_neon_aarch64.S` by `tools/gen_output_neon.py`,
  `blake3_output_sme2_aarch64.S` by `tools/gen_output_sme2.py`), the
  direct-load `Packed<16/32/48>` kernels (`blake3_packed_neon_aarch64.S`,
  generated by `tools/gen_packed_neon.py`; `blake3_packed_sme2_aarch64.S`,
  generated by `tools/gen_packed_sme2.py`), and the single-template
  `hash_counter_range` kernels (`blake3_counter_neon_aarch64.S` by
  `tools/gen_counter_neon.py`, using a stack template table;
  `blake3_counter_sme2_aarch64.S` by `tools/gen_counter_sme2.py`,
  keeping the template register-resident across the group loop).
- x86-64: official BLAKE3's SSE4.1, AVX2 and AVX-512 kernels, renamed,
  with the AVX2 and AVX-512 batch kernels' loads kept within each input
  (`blake3_{sse41,avx2,avx512}_x86-64_unix.S`); the 32-lane AVX-512
  batch kernel (`blake3_avx512_32.S`); the independent-compression
  output kernels (`blake3_output16.S` by `tools/gen_output16.py`,
  `blake3_output8.S` by `tools/gen_output8.py`); the fork's pass of
  whole chunks with a partial one (`blake3_partial_x86-64_unix.S`,
  generated by `tools/gen_x86.py`); the chunk root in one call
  (`blake3_chunk_root_x86-64_unix.S`, generated by
  `tools/gen_x86_chunk_root.py`); the direct-load `Packed<16/32/48>`
  kernels (`blake3_packed_x86-64_unix.S`, generated by
  `tools/gen_packed_x86.py`); and the single-template `hash_counter_range`
  kernels (`blake3_counter_x86-64_unix.S`, generated by
  `tools/gen_counter_x86.py`, register-resident on AVX-512 and using a
  stack template table on 16-register AVX2).

`tools/check-builds.sh` fails when a generated file and its generator
differ. The proofs of every kernel are in `tools/verify/` (its README);
BLAKE3-Servil's C API is `capi/b3.h`.
