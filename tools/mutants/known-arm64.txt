# The mutants known to survive the library's tests on an Apple silicon Mac
# (macOS names the architecture arm64), each with its reason;
# tools/mutants/check.py fails on any other survivor and on any listed one
# now caught. macOS leaves out code that Linux builds (what Linux asks its
# kernel about the CPU) and builds code of its own (what it asks macOS), so
# its mutants have a list of their own. The list began with a change to the
# GPU's code on an M4 Max (job 1909; that code left the tree on November 11,
# 2026). Since November 12 the rows are a Mac mini M6's, by the runner's
# whole runs (its mutants-whole job), the last of them on November 22.
#
# Both Macs run the SME2 kernels. A row that begins [cpu has FEAT_SME2]
# holds where they run: the CPU has SME2, the assembler built the kernels,
# and the streaming vectors are 512 bits long, all of which is so on the
# Macs that report the feature. A row that begins [cpu lacks FEAT_SME2] is
# for a Mac where they do not run. No such Mac has run these lists: those
# rows are the Arm VM's (known-aarch64.txt) or follow from reading the
# code, as each says, and they are not all that such a Mac would show. Its
# first whole run settles them.
# A line: file <TAB> mutant (function and change) <TAB> places <TAB> reason.
